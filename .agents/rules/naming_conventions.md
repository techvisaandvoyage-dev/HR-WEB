# Naming Conventions

- **Brand Name & Domain:** Always use `sahijob` and `sahijob.com`. Never add a trailing 's' (`sahijobs` or `sahijobs.com`).
- **Singular Form for Job UI Labels:** Use `job` instead of `jobs` in UI labels and headings across the website (e.g., "My Job", "Active Job", "All Job", "Post Job").
